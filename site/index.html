Torrents without the clutter.

Magnetar is a free, open-source BitTorrent client for Windows and Linux. Click a magnet link in your browser, choose the files you want, and let it run quietly in the tray.

Download Magnetar View the source Free, no ads, no tracking. Windows 10/11 and Ubuntu/Debian.

Everything you use, nothing you don't

Built in Go on the anacrolix/torrent engine, with an interface you can understand at a glance.

Everyday downloading

Magnet links from your browser
Click a link and Magnetar asks where to save it.
Pick files first
See every file and its size, and whether it fits on your disk, before anything downloads.
Picks up where it left off
Add a torrent again and only the missing pieces are fetched.
Statistics
All-time totals and a 24-hour bandwidth chart.

Control

Speed limits and a turtle mode
One click for slower limits, or let a schedule switch them during work hours.
Categories with folders
Movies here, Linux images there, finished downloads moved automatically.
Connection status
Tells you when peers cannot reach you, and how to fix it.
Updates itself
New versions install with one click and are verified before they run.

Privacy

Encryption by default
Protocol encryption is preferred, or required with one switch.
Stays on your VPN
Bind traffic to your VPN's address and it stops if the VPN drops.
Blocklists and anonymous mode
Block known bad ranges and hide the client's name from peers.
Nothing phones home
No telemetry, no accounts. The only outside check is an optional daily update check.

Install in a minute

No administrator rights needed on Windows. Every download is signed and can be traced back to the exact build that produced it.

Windows 10 and 11

Run the installer and choose Magnetar for magnet links.

Windows installer

For ARM PCs, pick the arm64 installer on the releases page.

Ubuntu, Debian, Mint

Download the package, then install it:

Download .deb 
sudo apt install ./magnetar_*_amd64.deb
magnetar register

Other Linux

Portable build for any distribution:

Download .tar.gz 
tar xzf magnetar_*_linux_amd64.tar.gz
cd magnetar_*_linux_amd64 && ./install.sh

Safe to run on your own computer

Magnetar's interface only listens on your computer, every request is authenticated, and updates refuse to install unless they carry the project's signature.

  • Signed releases. Built only by GitHub Actions, signed with Sigstore, with build provenance for every file.
  • Verified updates. The updater checks an Ed25519 signature and SHA-256 hash before installing anything.
  • Contained file access. File names in torrents can never reach outside your download folder.
  • Open source. Read every line on GitHub; security reports go through private advisories.
