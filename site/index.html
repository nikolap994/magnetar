Torrents without the clutter.

Magnetar is a free, open-source BitTorrent client for Windows, macOS and Linux. Choose what to download, watch while it arrives, cast to your TV, and manage it all from your phone.

Download Magnetar View the source Version . Free, no ads, no tracking. Windows, macOS, Linux and Docker.

Everything you use, nothing you don't

Built in Go on the anacrolix/torrent engine, with an interface you can understand at a glance.

Everyday downloading

Magnet links from your browser
Click a link and see what's inside, with an icon for every file, before you choose where to save it.
Play while it downloads
Watch videos and listen to music before the download finishes. Search and apply subtitles in the player, and get a clear warning when a media codec isn't supported.
Download queue
A few downloads at a time, the rest wait their turn and start by themselves.
Search and RSS
Search your own indexers in one place, or let feed rules pick new episodes automatically.
Cast to your TV
Cast video or audio from the player or a torrent menu. Magnetar finds compatible TVs on your network and streams the file while it downloads.
Find subtitles
Search OpenSubtitles with your API key and add subtitles to a video without leaving the player.

Control

Speed limits and a turtle mode
Exact limits, one click for slower ones, or a schedule for work hours.
From your phone
Enable phone access, set a password, and scan the QR code to add and manage downloads over Wi-Fi in a phone-friendly interface.
Bring your torrents
Import from another BitTorrent app with folders, file choices and statistics; files on disk keep seeding.
Tells you when it's done
A message on your phone, or sleep and shut down when everything has finished.

Privacy

VPN kill switch
Pick your VPN connection; if it drops, every transfer stops until it is back.
Encryption by default
Protocol encryption is preferred, or required with one switch. SOCKS5 and HTTP proxies too.
Blocklists and anonymous mode
Block known bad ranges and hide the client's name from peers.
Nothing phones home
No telemetry, no accounts. The only outside check is an optional daily update check.

Install in a minute

No administrator rights needed on Windows. Every download is signed and can be traced back to the exact build that produced it.

Windows 10 and 11

Installs for your account only, no administrator rights needed.

  1. Download the installer.

    Download for Windows

    For ARM PCs, pick the arm64 installer on the releases page.

  2. Run it and choose Yes to open magnet links and .torrent files with Magnetar.

    If Windows shows "Windows protected your PC", choose More info, then Run anyway.

  3. The first time you click a magnet link, Windows may ask which app to use. Pick Magnetar and tick Always.

Ubuntu, Debian, Linux Mint, Pop!_OS

A regular .deb package that adds Magnetar to your applications menu.

  1. Download the package.

    Download .deb

  2. Install it from the folder you downloaded it to:

    sudo apt install ./magnetar_*_amd64.deb

  3. Let your browser open magnet links with Magnetar:

    magnetar register

macOS 11 or newer

One app for Apple silicon and Intel Macs. It lives in the menu bar.

  1. Download the disk image.

    Download for Mac

  2. Open it and drag Magnetar to Applications.

  3. The first time, right-click Magnetar in Applications and choose Open.

Any other Linux distribution

A portable build that installs into your home folder.

  1. Download the archive.

    Download .tar.gz

  2. Unpack it and run the installer:

    tar xzf magnetar_*_linux_amd64.tar.gz
cd magnetar_*_linux_amd64
./install.sh

    Add --service to also start Magnetar in the background when you log in.

Docker on a server or NAS

The same interface in your browser, from any device on your network.

  1. Start the container:

    docker run -d --name magnetar --restart unless-stopped \
  -e MAGNETAR_PASSWORD='choose-a-password' \
  -p 8899:8899 -p 51413:51413 -p 51413:51413/udp \
  -v ./config:/config -v /path/to/downloads:/downloads \
  ghcr.io/nikolap994/magnetar:latest

  2. Open http://<server>:8899 and sign in with that password.

Safe to run on your own computer

Magnetar's interface only listens on your computer, every request is authenticated, and updates refuse to install unless they carry the project's signature.

  • Signed releases. Built only by GitHub Actions, signed with Sigstore, with build provenance for every file.
  • Verified updates. The updater checks an Ed25519 signature and SHA-256 hash before installing anything.
  • Contained file access. File names in torrents can never reach outside your download folder.
  • Open source. Read every line on GitHub; security reports go through private advisories.
